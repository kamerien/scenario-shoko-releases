# シナリオ書庫

TRPG のシナリオや、ココフォリア・Udonarium の部屋素材を、ドラッグ＆ドロップで取り込んで圧縮・管理する Windows アプリです。

## ダウンロード

[最新版のページ](https://github.com/kamerien/scenario-shoko-releases/releases/latest)を開き、`ScenarioShoko_〇〇_setup.exe` をダウンロードして実行してください。

- インストールすると、以後は起動時に新しい版を確認し、ボタン 1 つで更新できます
- `_update.exe` と `latest.json` は自動更新用のファイルです（手でダウンロードする必要はありません）
- 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください

このリポジトリは配布用で、ソースコードは置いていません。
